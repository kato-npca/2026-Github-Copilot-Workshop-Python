# API リファレンス

## 概要

現在の実装では、Flask は静的な HTML ページの配信のみを担当します。REST API エンドポイントは将来の拡張として設計段階では計画されていますが、現時点では実装されていません。

---

## 実装済みエンドポイント

### GET /

トップページ（タイマー UI）を返します。

**リクエスト**

```http
GET / HTTP/1.1
```

**レスポンス**

- **ステータスコード**: `200 OK`
- **Content-Type**: `text/html`
- **ボディ**: `templates/index.html` のレンダリング結果

**例**

```bash
curl http://localhost:5000/
```
